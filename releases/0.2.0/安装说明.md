# DivinityMC 0.2.0 测试版

运行环境为 Minecraft Java 版 1.21.1、NeoForge 21.1.265 和 Java 21。单人模式在客户端安装；联机时，服务端与每个客户端使用同一份 `divinitymc-0.2.0.jar`（网络协议 5）。

1. 解压测试包，将其中的 JAR 放入对应游戏实例的 `mods` 目录。如已装过 DivinityMC，先将旧 JAR 备份到 `mods` 以外的位置，确保目录中只保留一份。
2. 搭建独立服务器时，在新目录使用 NeoForge 安装器的「Install server」选项，或执行 `java -jar neoforge-21.1.265-installer.jar --installServer`。将同一个模组 JAR 放入服务端的 `mods` 目录，使用安装器生成的 `run.bat`（Windows）或 `run.sh`（Linux）启动。首次运行按服务端生成的 `eula.txt` 提示阅读并决定是否接受协议，然后再次启动。
3. 进入世界，查看普通铁胸甲的说明，应为 12 物甲／6 魔甲；穿上后双甲上限相应增加。上限提高不会立刻补满当前护甲。

Curios 是可选依赖。要使用饰品槽，客户端和服务端都安装适用于 NeoForge 1.21.1 的 Curios（实测 9.5.1+1.21.1）与饰品模组。普通防具无需额外安装 Curios。此前实测的暮色森林版本为 4.8.3345，Artifacts 版本为 13.2.5。

服务器配置在 `config/divinitymc.json`。拥有权限等级 2 的管理员可手持一件装备执行 `/divinitymc held` 查询实际容量及来源，或用 `/divinitymc held set 4 20` 只改变这一件。用 `/divinitymc held reset` 恢复默认值；整类装备的默认数值由 `/divinitymc equipment <物品ID> set <物甲> <魔甲>` 设置。
