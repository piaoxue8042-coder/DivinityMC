# DivinityMC 0.2.0 测试版说明

- 第三方防具按物品在对应穿戴槽实际提供的固定护甲加成换算。默认每 1 点护甲提供 2 物甲／1 魔甲。暮色森林的神秘王冠提供 4／2，旅行者手套与腰带为 0／0。旅行者防具损坏时容量降低，修好后恢复上限。
- Curios 功能槽支持自动换算、类型配置和单件编辑。外观槽不提供双甲，隐藏外观的功能槽仍然生效。没有固定护甲加成的饰品默认提供 0／0。
- 重锤「破甲」每级按减伤后物理近战伤害的 15% 额外消耗物甲，额外部分不会溢出为生命伤害。重击的范围击退也按每个附近目标自己的物甲和击退抗性判定。
- 装备上明确设置的单件属性优先于类型配置和自动换算。换穿高容量装备只提高上限，降低上限会立即截断当前值。
